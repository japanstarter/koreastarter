# KoreaStarter (koreastarter.com)

Calm, practical travel planning for South Korea — KTX trains, T-money, itineraries, and all 3,651 cities, districts & towns.

- **Country:** South Korea (대한민국)
- **Complete Municipality Coverage:** All **3,651** official cities, towns, and municipalities across **17** regions
- **Multi-Language Support:** 9 languages (`en`, `de`, `fr`, `es`, `it`, `nl`, `ja`, `ko`, `zh-tw`) with full `hreflang` alternates
- **Interactive Tools:** 14 client-side travel planning calculators & generators
- **Build:** Zero-dependency Node.js static & edge build (`node build.mjs`)
